# 产品宣传素材

`qimi-banner.png` 用于双语 README 与项目主页，表现栖密的本地保存、主密码保护和日常查找价值，不使用 Logo / 应用图标设计展示板。画面中的手机为宣传插画，不是实际 APP 截图；没有真实账号或密码。

Banner 先由 Dreamina `seedream_4.5` 生成，再通过内置 `imagegen` 定向修正指令残留、手机摄像头与多余控件。最终画面已实际查看；保留原生 PNG，不重新编码。核心生成与修图要求：

> 16:9 产品宣传画面，森林绿与暖白、自然光和植物投影、清楚的中英文产品文案、安卓手机中的合成账号列表。不得出现独立 Logo、App 图标、钥匙、盾牌、水印、色值或排版指令；密码使用圆点遮蔽，不暗示尚未实现的功能。

固定文案为“栖密 / Qimi”“密码留在本地，轻松留给日常。”“Passwords stay local. Everyday life feels lighter.”及“离线保存 · 主密码保护 · 快速查找”。

`qimi-list.png` 与 `qimi-detail.png` 来自本项目已验证的 S1 合成资料界面，由已知软件 View 树绘制导出，保留 APP 的安全窗口约束；不通过取消 `FLAG_SECURE` 截图。原图完整保留，界面中包含的账号和网址均为合成夹具。

`website/assets/` 中保留相同文件供独立静态主页部署。修改素材时同步两处，并检查字节摘要一致。品牌母稿与 Logo 展示另见[品牌资产](../brand/README.md)。
