## 执行规则与合成数据

记录构建/包摘要、设备系统、场景 ID、数据版本、结果及证据。状态为待执行、通过、失败、阻塞、不适用；后两者附原因。新增场景追加 ID。

测试仅用专用配置的合成库，保留用户现场。注入须定位持久化前/中/后，不以一次随机杀进程代表全部中断。扫描、截图不替代安全审查；设备测试使用独立创建的专用模拟器，不清理已有用户设备。

## 本地边界

### AC-01 离线与外流路径（A1）

- 前置：合成库、候选安装包、组件与依赖清单。
- 操作：飞行模式完成建库、暂存、搜索、生成、复制、恢复；联网重做并检查最终 Manifest、依赖、按 APP 身份归属的网络活动和外部调用。
- 预期：核心不等联网，无 INTERNET、联网 SDK 或上传任务。飞行模式只证明离线；外流路径另测 AC-03/04/12/14。
- 证据：包摘要、依赖/配置、两种环境结果与活动归属。

### AC-02 加密落盘与篡改（A2）

- 前置：F1–F4，已产生草稿、历史、快照与导出。
- 操作：扫描库、索引、辅助文件、缓存、系统状态和日志；在副本上篡改/截断后尝试打开。
- 预期：秘密和可读索引不明文落盘，主密码不可还原保存；损坏副本拒绝且不覆盖原库；日志无输入值。
- 证据：路径、方法、扫描及原库对照；扫描不证明密码学安全。

### AC-03 云备份排除（A3）

- 前置：专用设备、F4、独立测试备份，已知云备份通道。
- 操作：按系统官方测试流程触发云备份并恢复，检查库、草稿、密钥封装、快照及辅助目录。
- 预期：相关数据全部排除；恢复配置无旧库。allowBackup=false 与版本规则检查不能代替实测。
- 证据：系统/厂商、通道、规则和恢复目录对照；无法触发或观察则标阻塞。

### AC-04 D2D 与厂商迁移（A3）

- 前置：源/目标专用设备及 F4，列出系统和厂商迁移路径。
- 操作：逐条真实迁移，检查目标是否得到库、草稿、快照或本机密钥；主动备份恢复另作对照。
- 预期：自动迁移排除数据，换机走主动恢复；云备份通过不替代 D2D；未验证组合不列已验证支持。
- 证据：设备/工具版本、目录/启动结果；主动恢复归 AC-17。

## 记录与使用

### AC-05 建库、锁定与回退（A4、A12）

- 前置：首次启动与启用生物识别的 F1。
- 操作：跳过引导保存首条；触发后台/锁屏/超时/主动锁定，测试生物识别取消、失效及主密码回退，检查截图/任务预览。
- 预期：无强制可选权限；立即遮蔽且旧授权失效；生物识别失效不删库，错误解锁不自动销毁。
- 主密码长度边界：分别以 7 / 8 / 128 / 129 个 Unicode code points 建库，7 与 129 拒绝，8 与 128 可创建并用原值重开；补充含补充平面字符和首尾空格的合成口令，按 code point 计数且不裁剪、不规范化；未配对 UTF-16 surrogate 拒绝。已有主密码仍可解锁，无需迁移或改密。
- 证据：状态、预览、回退结果；认证/解密绑定需工程证据。

### AC-06 原文与多账号整理（A5）

- 前置：F2，无可信关联。
- 操作：粘贴暂存重开核对；多段逐条摘录，中断续办；单条整体转换；保存重名和未知方式。
- 预期：原文保真、整体默认隐藏；摘录有新 ID，源记录核对删除前保留；整体转换沿用 ID；不自动合并/信任/填充；未知提供方留待整理。
- 证据：源/目标 ID、原文与状态对照、确认及取消结果。

### AC-07 凭据保真与边界（A6）

- 前置：F3、不会主动改写输入的可信夹具。
- 操作：保存、重开、编辑、复制、填充；规范化搜索；超限输入与登录方式切换。
- 预期：逐字符原值一致，搜索派生值不覆盖；超限明确拒绝而不截断；验证码/第三方方式不静默删值、不填残留密码。
- 当前基础编辑：从详情进入并核对五字段预填；修改后保存，确认原 ID 不变、版本按提交更新且没有新增重复记录。校验失败不改库，写入失败沿原提交 / 回退契约处理且不虚报成功，两者均保留当前输入；无改动取消直接回详情，有改动可继续编辑或明确丢弃；后台 / 锁定后未保存输入丢弃，重开仍为最后成功版本。编辑没有草稿，草稿恢复仍归 AC-08 后续能力。
- 当前列表与详情：列表每行只有名称与固定 8 圆点密码遮罩，语义树与画面均无账号 / 域名 / 登录类型 / 实际密码长度；进入详情才核对原值。新增 / 详情无“账号密码”标记，列表 / 解锁无开发页脚，详情无常驻剪贴板提示；帮助页仍可查内部验证阶段、备份恢复未交付及剪贴板限制。
- 证据：编码序列对照、错误反馈及接收端结果；接收端改写单独定位。

### AC-08 草稿中断与冲突（A11、A12）

- 前置：已有条目基础版本，可注入持久化失败。
- 操作：落盘前/后锁屏或杀进程；恢复前改原条目制造冲突；恢复、丢弃、正式保存及空间不足分别测试。
- 预期：先遮蔽，完成或回退写入，不虚报保存；只恢复成功版本且不自动覆盖；提交原子清草稿，丢弃后不再恢复。
- 证据：成功版本/故障点时间线、原条目版本、草稿清除结果。

### AC-09 生成候选与应用（A1、A6、A11）

- 当前基础增量前置：专用合成设备，分别在新增与编辑表单保留原密码；核心规则可独立测试。编辑场景补核原记录只在正式保存时更新，不把未来草稿和生成器复制计入当前覆盖。
- 规则操作：检查初始普通 / 高级关闭；分别生成简单、普通、复杂；开启高级并尝试操作外层预设；高级全空、单项自定义、复杂程度未设置、长度 8 / 128 / 7 / 129 / 非整数以及四类字符的全部非空组合分别检查。
- 规则预期：三档分别为 12 位小写和数字、20 位大小写和数字、24 位大小写数字和符号；高级开启时预设不可操作且不参与生成。高级未设置复杂程度按普通；长度空、字符全不选各自回退到高级复杂程度默认值。明确选择的字符组合只包含所选类型，每类至少一个；长度必须精确一致，错误长度禁止生成并就地解释。符号覆盖全部 32 个 ASCII 可见标点，无空格。
- 界面操作：生成 / 重新生成后显示候选并等待隐藏；更改任一规则或模式，尝试使用旧候选；重新生成后分别取消、关闭、使用；应用后正式保存；面板和表单状态分别进入后台 / 锁定再解锁；在大字体与深色模式核对全部控件可达。
- 界面预期：候选默认隐藏，主动显示约 10 秒后隐藏；规则改变使旧候选不可用。生成及取消不改原表单，使用才填入表单，保存才写入正式库；生成器不复制、不暂存草稿。后台 / 锁定丢弃候选及未保存表单，重新打开面板恢复默认配置。隐藏语义不暴露候选或长度，窗口保留 `FLAG_SECURE`。
- 证据：规则单元测试、`SecureRandom` 与拒绝重抽实现审查、候选 / 表单 / 库三处值的变化及设备运行记录。随机结果不能靠一次肉眼观察或要求两次必不相同证明安全。
- 后续 S3 / S4 扩展验收：接入草稿后注入持久化失败，验证“使用并复制”先成功加密暂存才复制，失败保留候选而不复制；正式提交原子清草稿、保留历史。未接入前该部分保持待实施。

### AC-10 目标与错误匹配（A7）

- 前置：F5、多身份及待整理/归档/非密码条目。
- 操作：确认可信关联，访问异包、异签名、相似域名、未确认子域名及未知 WebView，尝试手选绕过。
- 预期：正常密码条目仅可信精确目标可选；名称/路径不赋信任，签名变化拒绝沿用；未知来源不填充且不能手选解除，提供复制回退。
- 证据：包名/签名/host、关联和实际接收字段；验证保持离线。

### AC-11 填充授权生命周期（A4、A7）

- 前置：分别在主 APP 密码库锁定、主 APP 已解锁两种状态下，由受控目标触发请求。
- 操作：看建议，检查已解锁主 APP 的外部请求仍需独立认证；选择后、释放前取消认证、变更目标、锁屏或过期；检查 APP 主会话。
- 预期：锁定不泄露身份；主 APP 已解锁不替代本次认证；失效请求不释放、不计使用；仅授权本次目标字段，不顺带解锁其他会话。认证取消不单独改变原主会话，主会话自身的后台/锁屏规则仍生效。
- 证据：请求/目标时间线、接收结果、会话及最近使用对照。

### AC-12 剪贴板与新内容（A8）

- 前置：合成值，记录系统行为和建议期限。
- 操作：复制后分别前台/后台/杀进程；到期前复制其他内容再返回，另测其他来源复制相同文本。
- 预期：有敏感标记，仅可靠确认本次写入时清理；不靠文本相同误清新复制；后台不能核验不盲清，文案不保证杀进程后按时清除。
- 证据：来源/时间线、到期/返回结果及文案；区分系统与 APP 清理。

### AC-13 历史与删除恢复（A6、A10）

- 前置：F1、多次变更及归档/待整理记录。
- 操作：恢复旧值、归档/取消、删除撤销/恢复，取消及完成永久删除和清历史。
- 预期：旧值恢复形成新修改；归档停止填充且复制须取消归档；恢复原状态；永久动作需主密码并清关联内容，不承诺快照/备份物理擦除。
- 证据：值/状态/填充资格、授权/取消和边界文案。

## 保全与恢复

### AC-14 本地出口与导出中断（A1、A9、A11）

- 前置：F4、可信本地/U 盘及未知第三方提供方。
- 操作：验证主密码导出至上述来源，在生成/校验/写出中断，重开检查。
- 预期：未知来源拒绝，不能确认绕过；完整校验文件才计成功，无误认半文件或可读索引；本机生成不等于独立转存。
- 证据：提供方身份/根目录、文件摘要、阶段结果及状态文案。

### AC-15 健康库验证与替换（A9、A11）

- 前置：当前库与另一备份使用不同测试主密码。
- 操作：只验证后替换；测错密码、保护副本失败、空间不足、确认前取消和完整替换。
- 预期：只验证不改数据/最近使用；需有效保护副本、当前主密码、覆盖确认；失败保原库，成功原子切换、不合并/重复，清楚区分密码用途。
- 证据：库/保护副本摘要、验证结果与数据对照。

### AC-16 损坏库独立恢复（A9、A11）

- 前置：损坏的测试库与有效快照/备份。
- 操作：保全故障文件，验证候选并切换；测保全失败、候选损坏、空间不足和切换中断。
- 预期：不要求解密损坏库；故障副本完整且不标有效备份；新库不覆盖现场；保全失败先解决存储，重开显示真实提交。
- 证据：故障摘要、候选验证、故障点及新库打开结果。

### AC-17 换机与信任重建（A9）

- 前置：独立介质上的 F4 和第二台支持设备。
- 操作：用备份主密码恢复，对照字段/状态/历史/草稿，检查旧生物识别及填充信任，再重新配置。
- 预期：不依赖源设备密钥，草稿不自动提交；设备绑定密钥/授权不迁移，新机重设生物识别并核对目标身份。
- 证据：两端版本、备份摘要、逐项对照及信任重建；本机解密不等于换机通过。

### AC-18 改主密码与旧备份（A10、A11）

- 前置：旧库、生物识别、独立旧备份及确定提交故障点。
- 操作：改密时中断或耗尽空间；重开试旧/新密码，检查快照与生物识别，再生成新备份并验证旧备份。
- 预期：完整旧或新状态，无半改密；新库拒旧密码；快照重保护或淘汰，失效识别回退；旧外部备份仍用旧密码，新备份失败另提示。
- 证据：故障点、提交/解锁状态、快照及两代备份结果。

### AC-19 写入与格式迁移（A11）

- 前置：验证过的原库、旧格式库及注入点。
- 操作：保存/迁移提交前中后中断；保护副本失败；低版本打开不兼容高版本文件。
- 预期：不半提交、不虚报/重复；保护失败停止依赖它的迁移；不兼容明确拒绝、不降级覆盖；有可验证回退。
- 证据：格式/构建、摘要、故障点、重开与回退结果。

### AC-20 可访问性与返回（A12）

- 前置：F1–F2、大字体、深色模式、读屏。
- 操作：遍历列表/表单/生成器/详情/回收站/备份/弹窗；返回、锁定再进入、取消操作，跳过并重开引导。
- 预期：内容可读、按钮触达，隐藏秘密不朗读；错误保留输入，上下文不绕授权；取消不改数据；提示可稍后、不每次登录强弹。
- 证据：页面矩阵、读屏/返回结果和观察记录。

### AC-21 同机回滚不恢复旧信任（A7、A9）

- 前置：合成库已有可信目标并创建同机快照，随后撤销目标关联或使其身份失效。
- 操作：恢复旧快照和旧外部备份，尝试使用历史目标候选；再次核验并明确关联后重试。
- 预期：恢复不激活历史设备授权或目标信任；关联保持待复核，认证和目标核验完成前不释放凭据；用户重新确认后按当前身份与条目状态判断资格。
- 证据：快照/备份代次、恢复前后信任状态、当前目标身份及实际接收结果；对应 SEC-14、UX-19。
