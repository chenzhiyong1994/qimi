## 本版范围

- 使用 8–128 个 Unicode code points 的主密码创建和解锁本地 KDBX 4.1 加密密码库。
- 新增或编辑名称、账号、密码、网址与备注，保留原值；编辑保存沿用原记录 ID 并检查基准版本。
- 按名称、账号或网址域名搜索；列表显示名称与固定密码遮罩，进入详情核对、显示或复制。
- 自动生成密码：简单、普通、复杂三档，默认普通；高级自定义支持选填复杂程度、8–128 位长度和多选字符类型，与外层预设互斥。候选确认使用后才填入表单，正式保存独立进行。
- 主动锁定、后台锁定、密码定时隐藏和敏感剪贴板清理；支持系统深色主题。
- 应用不申请 `INTERNET` 权限，不接入云账户、云同步、联网埋点或远程图标。
