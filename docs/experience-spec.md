# 页面与体验规格

本文维护 Android 首版的页面、控件、反馈、返回及文案。范围、状态和安全定义以 [产品方案](product-plan.md) 为准；密钥、可信目标、备份文件和写入机制由 [安全与数据规格](security-and-data.md)维护，测试步骤由 [验收场景](acceptance.md)维护。本文是完整首版设计基线，S1 实现其中的建库、新增 / 编辑、搜索、手动取用与提前接入的基础密码生成；实际覆盖与未验证边界见[项目状态](project-status.md)。

`P01`–`P14` 为稳定页面编号，`UX-01` 等为稳定交互规则编号；面板和向导子步骤沿用所属页面编号。时间、数量、尺寸及效率值是原型验证建议，不是已冻结技术参数；调整时同步产品方案和验收口径。首版不加入联网、云端 AI、批量自动合并或自动捕获改密。

## 1、页面与导航

**UX-01｜访问与返回。** 密码库锁定时只开放解锁、离线帮助和本地恢复入口，不显示名称、账号、条目数或最近活动。进入后台、锁屏或会话到期立即遮蔽并撤销交互授权；再次解锁后回到可恢复的页面，重新核对未完成动作，不能继续执行旧授权。

| 页面 | 名称与入口 | 主要控件、默认与反馈 | 返回规则 |
| --- | --- | --- | --- |
| P01 | 欢迎；尚未建库 | “创建密码库”“恢复本地备份”；一句话本地说明 | 系统返回退出，不建空库 |
| P02 | 建库 / 解锁；P01 或锁定 | 主密码输入、临时显示、生物识别、帮助；默认隐藏 | 取消不销毁库；自动填充认证取消则终止请求 |
| P03 | 密码库首页；解锁后 | 搜索、筛选、分组列表、新增、管理；空态提供两种录入 | 保留当前筛选和滚动；底部仅密码库 / 设置 |
| P04 | 条目详情；列表点击 | 账号、登录方式、密码、复制、编辑、历史、管理 | 回到原列表上下文；离开即遮蔽秘密 |
| P05 | 新增 / 编辑；新增或详情 | 最小表单、更多信息、生成器、保存；错误就地显示 | 当前编辑无变更直接回详情；有变更确认丢弃；未来草稿按其状态处理 |
| P06 | 零散原文；“粘贴零散记录”或待整理详情 | 输入 / 主动展开、保存、整理；整段默认隐藏 | 返回时隐藏正文；修改按草稿处理 |
| P07 | 整理核对；P06 | 源片段、建议字段、逐项核对、保存 | 取消不更改源记录或正式条目 |
| P08 | 密码生成器；P05 密码框旁“自动生成密码”打开底部面板 | 三档复杂度、高级自定义、候选、重新生成、使用；默认普通、高级关闭、候选隐藏 | 未使用候选丢弃，表单原密码不变 |
| P09 | 密码历史；P04 | 时间、隐藏旧值、恢复、清除；默认不展开 | 回到详情；恢复后刷新当前值 |
| P10 | 回收站；P03 管理入口 | 删除时间、恢复、永久删除、清空；不自动清空 | 回到原管理上下文，不混入普通搜索 |
| P11 | 自动填充；设置或系统请求 | 设置说明 / 认证 / 候选选择；显示可核对目标 | 取消不填充，不修改记录 |
| P12 | 备份与恢复；设置或 P01 | 快照、离线备份、验证、恢复向导；分别显示状态 | 提交前取消不改变当前库；提交后显示实际结果 |
| P13 | 设置；底部入口 | 安全、自动填充、备份、帮助、立即锁定 | 回到首页，保留筛选上下文 |
| P14 | 离线帮助 / 故障入口 | 主密码、换机、忘密、损坏、复制限制；问题对应行动 | 回到来源页，不要求提供真实密码库 |

新增菜单只有“新增账号”和“粘贴零散记录”。归档与回收站在管理入口；标签、收藏和待整理在页面内筛选。禁止用滑动手势直接永久删除。

## 2、首次成功与身份验证

**UX-02｜首次成功。** 无备份用户走 P01 → P02 建库 → P03 → P05 或 P06 → 保存成功；结构化条目可在 P04 主动复制一次。已有备份用户直接走 P12，不先创建无用的空库。首条保存前不要求分类、标签、生物识别或自动填充设置。

建库完成后使用本次有效主密码认证衔接首次会话；只有库创建提交成功才进入首页。首条保存后轻量介绍自动填充与离线备份，允许“稍后”，设置中始终能找到；不每次登录弹出，不显示虚构安全评分。

**UX-03｜主密码表单。** 创建时两个输入框明确标为“主密码”“再次输入主密码”；允许粘贴和空格，不裁剪。默认隐藏，临时显示按钮有清楚状态；确认不一致在第二个框下报错。主密码长度为 8–128 个 Unicode code points，界面提示与校验一致，不能暗中采用另一套规则。

解锁页提供“使用主密码”；生物识别取消不算密码错误。生物识别失效时解释需要主密码重新启用，不建议删库。验证失败显示剩余等待时间，等待结束恢复按钮，不用错误次数自动销毁数据。普通解锁与敏感操作重新验证使用不同标题，后者显示本次操作名称与对象范围；整库导出不以生物识别代替主密码。

P13 修改主密码依次核对旧主密码、新主密码与再次确认；提交前说明需要重新启用生物识别、旧外部备份仍使用旧主密码。成功后重新验证新主密码再进入密码库，并引导生成新备份；失败按实际提交点回退，不能只因确认输入一致就显示修改成功。

## 3、查找、详情与多账号

**UX-04｜首页与搜索。** 默认正常条目；收藏、最近成功使用和全部可分区，同一条目重复展示须能识别。搜索仅覆盖产品方案指定的名称、账号、域名、标签、别名，不搜索密码、原文或备注正文。排序按精确名称 / 域名、账号 / 标签、最近使用；不因修改记录更新“最近使用”。

搜索与筛选共同生效，筛选标记常驻并可一键清除；无结果显示当前条件和“清除筛选”“新增账号”。归档只能通过独立筛选或显式“包含归档”找到，回收站不参与。返回列表保留搜索、筛选、分组展开和滚动位置；这些上下文锁定时不得可见，也不得以明文存进系统页面状态。

**UX-05｜多账号。** 一条正式记录代表一个登录身份。当前 S1 列表每条只显示名称与固定 8 个圆点密码遮罩，不显示账号、域名或登录类型，也不暴露密码长度；同名记录进入详情核对。后续同平台分组与别名能力另行实施，不能自动合并记录或把平台名称当作目标信任。

后续同名或同账号提示“可能已有记录”时，须让用户核对后更新或另存，不得据此直接替换。别名、分组和重复提示未接入前，当前列表通过进入详情区分身份，不用条目序号暗示它们是同一身份。

**UX-06｜详情与复制。** 非密码方式不显示空密码按钮；第三方登录明确展示提供方。密码用固定数量遮蔽符，不暴露长度；账号只在详情核对原值。当前详情不展示“账号密码”类型标记，也不常驻剪贴板说明；复制的实际限制保留在离线帮助。隐藏字段的按钮标为“显示密码”“复制账号”“复制密码”，不得靠图标猜用途。显示密码建议约 10 秒后遮蔽，离开、后台或锁定立即遮蔽。

复制只复制原字段，不拼接标签、不裁剪、不改大小写。成功反馈不带明文，建议“已复制；支持时将在约 30 秒后清除”。清理是否发生以实际系统条件为准，不误清用户后来复制的其他内容。归档条目复制前先取消归档；回收站条目先恢复，原文复制必须由用户主动展开和选择。

## 4、录入、登录方式与草稿

**UX-07｜最小表单。** 当前 P05 首屏呈现名称、账号和密码，网址与备注可展开，不展示单一“账号密码”类型标记；名称和密码必填，账号允许空，不强制邮箱格式。下表的其他登录方式，以及别名、标签、收藏和“保存到待整理”属于后续能力，接入后仍不能把缺密码条目伪装成正常记录。

| 登录方式 | 必需与展开内容 | 禁止的行为 |
| --- | --- | --- |
| 账号密码 | 名称、密码；账号选填，生成器可用 | 密码空仍保存为正式条目 |
| 短信验证码 | 名称；账号标为接收手机号，不强制国家格式 | 自动读取短信或提供密码填充 |
| 邮箱验证码 | 名称；账号标为接收邮箱 | 自动读取邮件或混称短信登录 |
| 第三方登录 | 名称、提供方；关联身份和使用提示选填 | 未知提供方冒充已确认正式信息 |
| 暂不清楚 | 提示保存待整理，保留原始输入 | 解析后直接转为正式条目 |

切换方式不静默删除已输入密码；密码被保留但当前方式不使用时，显示“已保留此前输入的密码，此登录方式不用于密码自动填充”。切回可继续编辑。只有账号密码方式、正常状态且目标通过验证才可能成为填充候选。

**UX-08｜保真与保存。** 账号、密码、原文均按原值保存、显示、复制和填充；换行、首尾空格和特殊字符不能被预处理改掉。字段上限按产品方案建议值，超限在对应字段说明如何缩短或分段，不静默截断。正式保存校验失败保留全部输入并定位首个错误；成功才显示“已保存”并进入详情。

当前 S1 从详情进入“编辑”，复用新增表单并原值预填名称、账号、密码、网址、备注。保存携带原条目 ID 与编辑基准版本，沿既有可验证提交更新原记录；校验、版本冲突或写入失败保留当前输入并反馈，不能虚报成功。无修改返回直接回原详情；有修改须选择继续编辑或明确丢弃。没有草稿，后台 / 锁定丢弃全部未保存输入及生成候选，原正式条目保持已提交版本；不承诺中断恢复。

**UX-09｜草稿。** 本规则属于尚未接入的可恢复草稿能力。保存状态固定在表单可见位置：“尚未保存”“正在保存草稿”“草稿已保存”“草稿保存失败”。只有成功落盘后才显示完成；状态不得仅由计时器决定。正常返回时，已有成功草稿可回列表并说明未正式保存；当前变化未落盘则允许继续编辑、重试或明确丢弃未保存变化，不能显示可恢复保证。

中断后只承诺最近成功落盘版本。解锁后提供“恢复草稿”“丢弃草稿”，不自动提交；存在较新正式版本时展示冲突，核对后选择基于当前记录继续或另存，避免旧草稿覆盖新数据。草稿不参加搜索结果中的正式记录或自动填充。

## 5、零散原文与整理

**UX-10｜先记再整理。** P06 空表单允许输入或点击粘贴；非空即可保存待整理。默认使用不含源正文的标题，例如“待整理记录”；列表与详情都不展示首行、关键词或任意正文片段。已保存原文整段隐藏，主动点击“展开原文”才可见，离开即隐藏；后台不预读剪贴板。

**UX-11｜核对转换。** P07 本地规则只给建议，建议字段标为“待核对”，原片段可对照但不改写。用户逐项核对名称、账号、登录方式、密码及网址；保留字符和换行，无法可靠提取的部分留在源记录中。原文的网址不自动取得自动填充信任。

单条整体转换沿用源 ID；多账号拆分采用“选片段 → 保存一个新条目 → 返回继续”，每个新条目有独立 ID，源记录保留。保存失败停在核对页，不标记该片段完成。拆分完成后仍让用户核对已保存条目，再主动确认删除源记录；不能仅凭解析数量推断全部完成。整条转换后残留原文仍隐藏，清理须显式确认，并说明快照和外部备份可能保留。

## 6、生成、历史与管理

**UX-12｜生成器。** 从新增 / 编辑账号表单打开 P08。每次打开默认选“普通”，高级自定义关闭；仅提供随机密码，不提供随机口令。三档名称表示生成规则，不保证符合所有平台的密码限制。

| 复杂度 | 默认长度 | 字符类型 |
| --- | --- | --- |
| 简单 | 12 | 小写字母、数字 |
| 普通 | 20 | 大写字母、小写字母、数字 |
| 复杂 | 24 | 大写字母、小写字母、数字、符号 |

高级自定义打开后，外层三档复杂度选项禁用，生成只读取高级规则；关闭后恢复外层预设。高级字段均选填：独立的“复杂程度”未设置时按普通，长度为空时采用该高级复杂程度的默认长度，字符类型全部未选时采用该高级复杂程度的默认组合。长度填写时须为 8–128 的整数；字符类型支持大写字母、小写字母、数字、符号多选，明确选择后只使用所选类型，且每类至少一个字符。字母与数字使用 ASCII，符号为全部 32 个 ASCII 可见标点，不含空格。界面说明空值的默认规则与当前生效组合，长度错误就地提示并禁止生成。

生成或重新生成只更新面板候选；候选默认隐藏，主动显示约 10 秒后再次隐藏。切换模式或修改任一规则使旧候选失效，重新生成前不能使用。候选仅在当前授权会话内存保留，关闭、取消不改变原表单密码；“使用此密码”才将有效候选填入表单并关闭面板，正式保存是独立动作。后台、锁定或离开未保存表单均遵循 S1 的丢弃边界，不能承诺候选或输入可恢复；生成器内不提供复制。

后续 S3 / S4 的草稿衔接另行实施：“使用”尝试保存加密草稿；“使用并复制”须先成功落盘再复制，失败保留候选供重试。当前新增 / 编辑表单不包含这两个持久化行为。APP 不替用户完成目标平台改密。

**UX-13｜密码历史。** P09 时间列表默认隐藏旧值；按产品方案建议保留最近 5 次变更。恢复前说明将更新当前本地密码，目标平台不会同步改变；确认后作为新修改保存，不删除后续历史。清除历史须重新输入主密码并说明旧备份边界，取消不改变历史。

**UX-14｜归档与回收站。** 归档停止自动填充，详情只读；先取消归档才编辑或复制。删除先确认，成功 Snackbar 提供撤销；撤销失败明确反馈，仍可去 P10 恢复。回收站默认不自动清空，显示删除时间与占用情况；不显示或复制秘密，恢复回到原状态，包括已归档状态。永久删除 / 清空须重新输入主密码，确认范围与数量；完成后不承诺擦除所有历史副本。

## 7、自动填充

**UX-15｜设置与权限节奏。** P11 说明用途后打开系统自动填充设置，不请求无障碍、悬浮窗或联网权限。返回检查实际启用状态，用户离开系统设置不等于启用成功。失败可重试或查看离线说明；不用必须启用才能继续的弹窗。

**UX-16｜目标与账号选择。** 系统请求先验证目标，再认证；认证前不显示候选身份。候选展示可信目标、别名、账号摘要及可选择操作；选择只释放本次账号密码。首次原生 APP 关联需要用户核对目标，界面使用可读应用名称辅助，但包名和签名身份验证按安全规格执行，名称相同不是信任证明。

相似域名、签名变化或无法确认归属的 WebView 不提供凭据候选；未知 WebView 不能通过“手动选择条目”放宽限制。提示“无法确认当前登录页面的归属。请返回密码库核对后手动复制。”复制是用户主动回退，不能把它包装成来源已安全。

可信目标无匹配条目时提供返回 App 搜索或新增；存在多个账号必须明确选择。取消、锁屏、目标变化或请求过期均终止授权；重试必须取得当前新请求，不能用解锁前缓存目标继续填充。不把已填入等同于目标平台登录成功。

## 8、备份、恢复与失效

**UX-17｜备份概览。** P12 将“设备内快照”和“离线备份”分成两块。快照显示可用版本和失败状态，说明设备丢失时一起丢失；离线备份分别显示文件生成、解密验证、另一设备恢复的实际状态，不推断用户已转存。系统云迁移不作为换机入口。

**UX-18｜导出。** 重新输入当前主密码 → 生成并校验 → 选择经验证的本地位置 → 完成。阶段进度有文字，提交期间防重复点击；不是实际字节进度就不编百分比。来源 / 位置不能确认本地性时禁止继续，不能用“风险已知，继续”绕过。成功显示文件位置与时间，引导转存电脑 / U 盘及验证；不调用任意分享面板。

**UX-19｜恢复向导。** 选择本地文件 → 输入“此备份创建时的主密码” → 验证 → 预览时间、数量和格式 → 只验证 / 导入。未解密前不展示密码库内容。当前库非空时只提供“只验证，不导入”或“替换当前库”，不增加首版多库与合并。

替换前必须完成当前库保护副本并验证当前主密码，再最终确认；备份主密码与当前主密码的输入框标题区分。按钮显示“替换当前密码库”，不用含糊的“继续”。任一步失败不改当前库；只验证成功不更新最近使用。新设备成功恢复后，引导重设生物识别与自动填充；原有关联显示“待重新核对”，不因恢复成功自动激活目标信任，本机快照恢复同样复核。

**UX-20｜损坏与忘密。** 已确认损坏时进入 P14 → P12 故障恢复，先保全故障文件，再验证恢复来源并切换；不要求先解密损坏库。保全失败明确说明存储问题，保留现场。忘密时按产品方案 10.2.7 区分可用生物识别与完全无法解锁；不提供客服重置、无主密码整库导出或万能恢复码。

**UX-21｜中断后的真实结果。** 锁定优先，导出、恢复和保存不能延迟遮蔽。回来后查询实际提交结果：“已完成”“未完成，原数据未变”“需核对恢复检查点”；不因上次按过按钮自动重做。取消、返回、进程终止、空间不足的处理按同一规则，错误说明下一步，不要求卸载重装。

## 9、可访问性、文案与验证

**UX-22｜无障碍与设置。** P13 随系统深色模式、字体与显示缩放；正文放大时可滚动，主按钮和错误不被键盘遮住。建议触控区域至少 48 dp，重要控件不用仅靠颜色表达；建议正文对比度至少 4.5:1，具体视觉稿与设备实测确认。表单标签不只放占位符；错误、成功和保存状态提供读屏反馈，不在每次输入时重复打断。

读屏默认只读“密码已隐藏”和显示 / 复制按钮，不读秘密、秘密长度或候选内容。用户主动显示后可以访问内容，离开立刻恢复隐藏；自动填充候选读出可区分的别名、脱敏账号与目标，不带密码。显示状态、展开分组和选中状态有可访问名称；Snackbar 的撤销动作可获得焦点，回收站提供长期回退入口。

**UX-23｜关键文案。** 不使用“绝对安全”“永不丢失”“已永久擦除所有副本”或“已同步”。以下为可维护文案基线，安全边界变化时同步来源规格。

| 位置 / 状态 | 建议文案 |
| --- | --- |
| P01 | “账号和密码加密保存在本机，无需注册。” |
| P02 建库 | “请记住主密码。忘记且没有可用解锁方式时，密码库可能无法恢复。” |
| P05 草稿成功 | “草稿已加密保存，尚未保存为正式记录。” |
| P05 草稿失败 | “这些修改尚未保存。请重试；关闭后可能无法恢复。” |

| P12 快照 | “快照仍在这台设备上，不能防止设备丢失。” |
| P12 导出完成 | “加密备份已生成。转存至独立介质并验证后，才有设备丢失时的恢复来源。” |

效率目标沿用产品方案第 4 章，不另设竞争门槛。原型观察重点：首次成功、先记后整理、多账号区分、生成器取消、失效目标回退、两套主密码的恢复理解。使用合成资料完成 [验收场景](acceptance.md)；实际 UI 验证按[记录](validation-s1.md)区分子项，完整首版读屏、系统选择器、自动填充和性能验收仍待执行。

## 10、S1 当前界面实现

本节记录当前界面范围，不扩大前述完整首版功能覆盖；本轮编辑与列表调整的验证以[验证记录](validation-s1.md)为准。建库 / 解锁、列表、新增 / 编辑、详情和帮助采用统一卡片、森林绿操作色、暖白背景和少量淡金点缀，跟随系统深色模式与字体缩放。图标在本机绘制，不下载网站图标或字体；文字标签保留，纯图标操作有可访问名称。

建库 / 解锁页展示品牌标题“栖密”，主文案统一为“密码留在本地，轻松留给日常。”，在逗号处分行展示；品牌定义由[产品方案](product-plan.md)维护。

建库 / 解锁与列表页的顶部使用“栖巢与钥匙”品牌标记，按主题色着色。桌面图标采用森林绿底、暖白标记和系统 adaptive 遮罩；Android 13+ 提供同轮廓主题图标。品牌标记为装饰，邻近“栖密”文字保留；锁定与其他操作继续使用原功能图标。

搜索框在有输入时提供一键清空。列表只呈现名称与固定 8 圆点密码遮罩；滚动位置只在同一授权代次的内存保留，详情返回可回到原列表上下文；锁定时销毁，不保存到系统页面状态。新增 / 编辑首屏只呈现名称、账号和密码，网址与备注以“添加网址与备注”展开；编辑时预填五字段，已有网址 / 备注可见；未修改内容时保存按钮禁用，避免产生重复历史。“账号密码”类型标记从新增与详情移除。解锁与列表不展示开发说明页脚，详情不常驻剪贴板提示；内部测试阶段、备份恢复未交付和剪贴板限制仍在帮助页说明。

主密码输入支持 IME Done 提交并收起键盘，显示操作仍约 10 秒自动隐藏。详情复制成功后，按钮短暂显示“已复制”约 2.5 秒，再回到原操作名称；这仅是反馈状态，不代表剪贴板清理已完成。读写有文字和进度反馈，错误出现时滚动到页面顶部，以便看见实际失败原因；未更改保存成功、复制保真、会话撤销或剪贴板清理的判断条件。

2026-10-01 的独立 `UiPolishProbe` 曾通过 2 项只读检查，覆盖当时普通界面以及 `font_scale=1.5` / 系统深色的五个页面与主要控件可达性，检查前后已有合成库字节相同。仅对完整已知 S1 夹具导出软件绘制图像，窗口 `FLAG_SECURE` 保持启用；证据与运行方式见[开发文档](development.md)。该历史结果不代替本轮界面验证、完整 S1 回归、TalkBack、所有字体缩放档位或真实设备验收。
